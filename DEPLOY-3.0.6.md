# V3.0.6 Güncelleme

1. Supabase SQL Editor'da `supabase/repair-v3.0.6-branding.sql` çalıştırın.
2. Paketi mevcut repo üzerine `.git`, `.env.local`, `node_modules`, `.next` korunacak şekilde kopyalayın.
3. `npm install`
4. `npm run typecheck`
5. `npm run build`
6. `git add -A && git commit -m "v3.0.6: Figma icons + branding CMS + document filters" && git push`
7. Vercel deploy sonrası CMS > Site Ayarları > Marka & Web Sitesi İkonları bölümünden görselleri yükleyip `TÜM AYARLARI KAYDET` butonuna basın.
